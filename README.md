# 💝 Joyeux Anniversaire Mon Amour

Une page web interactive pour célébrer nos 5 ans ensemble.

## 📁 Structure du Projet

```
Sanda's birthday/
├── index.html          # Page principale
├── style.css           # Styles de la page
├── script.js           # Fonctionnalités JavaScript
├── README.md           # Ce fichier
└── assets/
    ├── music.mp3       # Musique de fond
    ├── photos/         # Dossier des photos
    │   ├── photo1.jpg
    │   ├── photo2.jpg
    │   ├── photo3.jpg
    │   └── finale.jpg
    └── videos/         # Dossier des vidéos
        ├── video1.mp4
        └── video2.mp4
```

## 🎯 Sections

1. **Accueil** - Titre d'anniversaire avec bouton de démarrage
2. **Notre Histoire** - Introduction
3. **Nos Souvenirs** - Galerie de photos
4. **Nos Plus Beaux Moments** - Vidéos
5. **Ce Que J'Aime Chez Toi** - Liste personnalisée
6. **Compteur** - Nombre de jours ensemble
7. **Lettre** - Message personnel
8. **Fin** - Conclusion avec photo de fin

## 🎵 Configuration

- Remplacez les fichiers dans `assets/` par vos propres fichiers
- Modifiez la date de départ dans `script.js` pour un compteur précis
- Personnalisez les textes dans `index.html`

## 🚀 Utilisation

1. Ouvrez `index.html` dans un navigateur
2. Cliquez sur "Commencer notre histoire" pour lancer la musique
3. Parcourez les sections en scrollant

## 💝 À Personnaliser

- Textes dans `index.html`
- Photos et vidéos dans `assets/`
- Couleurs et styles dans `style.css`
- Date de départ dans `script.js`
